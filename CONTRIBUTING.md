# Contributing

Stage 1 (oracle parity, drop-in ABI) is complete; Stage 2 — bug-for-bug
compatibility with the pin, with internal improvements — is current; Stage 3
(opt-in departures from the pin) follows — see
`ROADMAP.md`. Run the README Quickstart (fmt / clippy / test);
`docs/runbooks/` has the procedures for everything beyond it.

Every contributor remains responsible for understanding, reviewing, testing,
and maintaining the changes they submit.
