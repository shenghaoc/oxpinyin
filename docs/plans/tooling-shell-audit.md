The [placement rule and migration units](tooling-python.md#shell-placement-rule-1260)
are authoritative for interpreting the table. **Migrated** means the shell entry
was removed and its work now runs through the named Python services after
provisioning. **Retired** identifies the removed legacy test control. A workflow `run:` or a Docker `CMD`
is repository-owned, not an outside requirement for a shell entry point.
An image-build `RUN` without managed CPython is a concrete environment reason.
System `python3` in a build image does not meet the managed-interpreter contract.

Caller searches used both each full path and its basename across tracked text
(`git grep -I -n -F -e PATH -e BASENAME -- .`), then inspected the matching
code. The table separates calling code from test references; comments, docs,
CI change filters and recipe-hash input lists are not execution callers.
Generic names (`runtime.sh`, `check.sh`, `run-sanitizers.sh`, `pc-version.sh`)
are disambiguated by their directory and source expression. Registry calls mean
`tools/bisection/run-all.py` executes the row's command from `runners.json`;
`tools.dev` list/plan read that same registry. At the source snapshot, shell tests
without an executable caller were manual tests; `test-tools` discovers Python
tests. CI enumerates the currently tracked shell scripts for ShellCheck.

The completed migrations preserve argv boundaries (including empty/spaced
arguments), defaults, stdout/stderr bytes and order, exit/return statuses
(including child and signal failures), environment meanings, cwd/loader-path
resolution, file outputs and cleanup. The per-row interface column adds the
source's usage and environment reads; literal status branches are not a complete
enumeration of dynamic/child statuses. Source-only libraries require migration
of every function consumer, not a subprocess pretending to modify its parent.
Temporary output retention follows CONTRIBUTING, rather than old capture prose.

the reader returned, against a `U3_BASE` tree that still carries it.

inventory, the git-ignore refusals, the `verified` marker format, the

inventory from it. `tools/dev/model.test.py` carries the contract the Rust
`fetch_script` tests in `crates/pinyin-oracle/tests/model_fetch.rs` held; that
file keeps only the locator tests. A missing `--cache-dir` value now prints
`option needs a value` with status 2, where Bash's unbound-variable error gave
status 1.
