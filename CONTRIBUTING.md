# Contributing

Stage 1 (oracle parity, drop-in ABI) is complete; Stage 2 — bug-for-bug
compatibility with the pin — is current; Stage 3 (performance) follows — see
`ROADMAP.md`. Run the README Quickstart (fmt / clippy / test);
`docs/runbooks/` has the procedures for everything beyond it.

```sh
git config core.hooksPath .githooks   # once per clone
```

AI assistants must follow `AGENTS.md` (`Assisted-by: AGENT:MODEL`; set
semantics).
