Status: **attributed on one cloud host; gap not reproduced there.** Refs
#1090, #1106. Two campaigns are recorded. The desktop BDB campaign (10:37Z,
below) measured the warm gap: ox/pin init wall 1.005, 1.011, 1.049 and 1.040,
all intervals above 1.00. The cloud campaign (13:10Z–14:02Z) ran the new
init attribution stage on BDB and KC, subject, control and pin in one run on

[0.994, 1.032], 1.075 [1.041, 1.144], 0.960 [0.926, 0.994], 1.046

contributors below are the differences between ox and pin that hold in every

the startup tier was evaluated and not adopted ("Startup-tier reorder"). No
product code changed. No captures were created, committed, attached or

### Startup-tier reorder: evaluated, not adopted

Proposal: write the policy's `init` tier with init's own functions first, in
first-use order, and the rest of the tier after them. Ruling (maintainer,
turn received by 15:48 UTC): not adopted. The estimate moves 16/17 executed
`.text` pages from init to the first candidate. The ruling rests on the
modelled load-to-M1 startup footprint:

- executed `.text` pages go from 95/99 to 98/98 (+3 / −1);
- 64 KiB fault-around windows stay at 7.3/7.4.

The first candidate is also already the larger gap (#1031).

**Model.**

- Objects: the BDB libraries of the cloud campaign (`224f0fde…`,
  `0fa81c42…`). The ordered prefix is the span of the policy's `init` tier
  in `.text` (`teardown.policy_prefix`): libzhuyin `0xe060`–`0x7529c` (256
  function bodies), libpinyin `0x10060`–`0x79297` (272). A body is a sized
  `.text` symbol from `nm -S`; aliases at one address count once.
- Placement: bodies are laid out from the prefix start in a given order,
  each at the next multiple of min(16, the lowest set bit of its current
  address).
- Before: the current (name) order. After: init's prefix functions in
  first-use order, then every other prefix function in its current order.
  Code after the prefix keeps its address.
- An executed instruction moves with its function and counts the 4 KiB file
  pages of its first and last byte.
- Inputs, phrases profile, warm: init's instructions in first-use order
  (Lackey, between the init markers); the executed instructions of the load
  constructors and of the first candidate (Callgrind `--dump-instr=yes`,
  toggled on each `.init_array` constructor and on the exports `teardown.h`
  calls from init to M1, `FIRST_CANDIDATE` in
  `tools/generate-function-order.py`); instruction lengths from `objdump -d`.

**Checks.**

- Placement in the current order reproduces the address of every prefix
  function: 0 mismatches in 256/272, and the same prefix end. The after
  order ends at the same address, so nothing after the prefix moves and the
  object size does not change.
- Before, init executes 74/75 `.text` pages (14–113 / 16–119), the figures in
  the table above.
- Callgrind toggled on `<facade>_init` records 14,094/14,903 init
  instructions. Lackey's window holds the same instructions plus 7: one `.plt`
  stub and six instructions in two functions, all on pages that init executes
  in both orders.
- The stage's equivalence was COMPARABLE for both facades.

**First use and the first candidate.** Init executes 128 (zhuyin) / 138
(pinyin) sized functions, all in the prefix, 240,020 / 245,773 B. The model
moves these. The executed-code table above counts 129/139 with the same
bytes. That count also holds one `.plt` entry: the init-pages record groups
addresses that no sized symbol holds by section, and the PLT stubs init
calls through have no symbol. The first-use order starts

`reorder_collect.py`:

```python
"""Scratch (not committed): collect init's ordered instructions (Lackey,
between the worker's init markers) through teardown's init-attribute stage,
reduced to the `pages` probe and no Ir. Writes one JSON per facade/side.

usage: reorder_collect.py ROOT OUT_DIR -- <contract-diff.py arguments>
"""
import importlib.util, json, re, sys
from pathlib import Path

root, out = Path(sys.argv[1]), Path(sys.argv[2])
assert sys.argv[3] == '--'
sys.path.insert(0, str(root / 'tools/bisection'))
import teardown

LINE = re.compile(rb'^(I | [LSM]) +([0-9a-f]+),([0-9]+)$', re.M)


class OrderedLackey(teardown.LackeyAccesses):
    """LackeyAccesses plus the first-seen order of instruction addresses."""

    def __init__(self):
        super().__init__()
        self.order, self.sizes = [], {}

    def feed(self, block):
        text = self.rest + block
        cut = text.rfind(b'\n') + 1
        window = text[:cut]
        state = self.state
        super().feed(block)
        if state == 'before':
            begin = re.search(rb'(?m)^B', window)
            if not begin:
                return
            window = window[begin.end():]
        elif state != 'inside':
            return
        end = re.search(rb'(?m)^E', window)
        for kind, address, size in LINE.findall(window[:end.start()] if end else window):
            if kind == b'I ':
                start = int(address, 16)
                if start not in self.sizes:
                    self.sizes[start] = int(size)
                    self.order.append(start)

    def result(self):
        value = super().result()
        value['order'] = [[address, self.sizes[address]] for address in self.order]
        return value


teardown.LackeyAccesses = OrderedLackey
teardown.INIT_PROBE_ROUNDS = {'pages': (1, 0)}
teardown.INIT_IR_ROUNDS = 0
teardown.report_init_ir = lambda *args, **kwargs: False


def dump_pages(facade, case, rows, bitmaps, subjects, cache):
    for side, samples in rows.items():
        row = samples[0]
        library = subjects[side][facade].resolve()
        document = dict(facade=facade, case=case, side=side, library=str(library),
                        maps=row['checkpoints'][1]['I1']['maps'], window=row['init']['accesses']['window'],
                        order=row['init']['accesses']['order'])
        (out / f'init-{facade}-{case}-{side}.json').write_text(json.dumps(document))
        print('dumped', facade, case, side, len(document['order']), document['window'], flush=True)


teardown.report_init_pages = dump_pages
for name in ('report_init_counts', 'report_init_samples', 'report_init_faults', 'report_init_trace'):
    setattr(teardown, name, lambda *args, **kwargs: None)

spec = importlib.util.spec_from_file_location('contract_diff', root / 'tools/bisection/contract-diff.py')
module = importlib.util.module_from_spec(spec)
sys.modules['contract_diff'] = module
spec.loader.exec_module(module)
sys.argv = ['contract-diff.py', *sys.argv[4:]]
sys.exit(module.run_main())
```

`reorder_fc.py`:

```python
"""Scratch (not committed): executed instruction addresses of one facade's
load constructors and of the exports the teardown worker calls between I1 and
M1 (generate-function-order's FIRST_CANDIDATE list), from Callgrind with
--dump-instr=yes, toggled the way the generator collects the startup set.

usage: reorder_fc.py ROOT WORKER FACADE LIBRARY DATA PROFILE_USER CPU SCRATCH OUT
"""
import json, os, re, runpy, shutil, subprocess, sys
from pathlib import Path

root, worker, facade, library, data, user, cpu, scratch, out = sys.argv[1:]
library = Path(library).resolve()
gfo = runpy.run_path(str(Path(root) / 'tools/generate-function-order.py'))
sys.path.insert(0, str(Path(root) / 'tools/bisection'))
import teardown


def run(toggles, label):
    copy = Path(scratch) / f'user-{facade}-{label}'
    shutil.rmtree(copy, ignore_errors=True)
    shutil.copytree(user, copy)
    command = ['taskset', '-c', cpu, 'valgrind', '--tool=callgrind', '--cache-sim=no', '--branch-sim=no',
               '--demangle=no', '--dump-instr=yes', '--collect-atstart=no',
               *[f'--toggle-collect={toggle}' for toggle in toggles],
               '--callgrind-out-file=/dev/stderr', worker, '--teardown', facade, str(library), data,
               str(copy), 'time', '0', '1', '1', 'first-candidate', '-']
    env = dict(os.environ, LC_ALL='C', TMPDIR=scratch, OXPINYIN_TEARDOWN_EXPORTS=','.join(teardown.exports(facade)))
    done = subprocess.run(command, capture_output=True, env=env)
    shutil.rmtree(copy, ignore_errors=True)
    if done.returncode:
        raise SystemExit(f'{label}: exit {done.returncode}: {done.stderr[-2000:]!r}')
    return parse(done.stderr.decode())


def parse(text):
    tables = {'ob': {}, 'fn': {}}
    current_ob = current_fn = None
    last = None
    positions = None
    after_call = False
    found = {}

    def decode(kind, body):
        match = re.fullmatch(r'\((\d+)\)(?:\s+(.*))?', body)
        if not match:
            return body
        number, name = match.groups()
        if name is not None:
            tables[kind][number] = name
        return tables[kind][number]

    for line in text.splitlines():
        if line.startswith('positions:'):
            positions = line.split()[1:]
            if positions[0] != 'instr':
                raise SystemExit('no instruction positions')
        elif match := re.match(r'^(c?)(ob|fn)=(.*)$', line):
            callee, kind, body = match.groups()
            value = decode(kind, body)
            if not callee:

                else:

            after_call = True
        elif line and line[0] in '0123456789+-*' and positions:
            field = line.split()[0]
            if field == '*':
                address = last
            elif field[0] in '+-':
                step = int(field[1:], 0)
                address = last + step if field[0] == '+' else last - step
            else:
                address = int(field, 0)
            last = address
            if after_call:
                after_call = False
                continue
            if current_ob and Path(current_ob).resolve() == library:
                found[address] = current_fn
    return found


constructors = gfo['init_array_symbols'](library)
load = {}
for toggle in constructors:
    load.update(run([toggle], 'load-' + toggle[:40]))
toggles = [f'{facade}_{name}' for name in gfo['FIRST_CANDIDATE'][facade]]
```

```python
"""Scratch (not committed): model the startup prefix with init's functions
first, in first-use order, and the rest of the prefix in its current order.

usage: reorder_model.py ROOT FACADE INIT_JSON FC_JSON
"""
import collections, json, re, subprocess, sys
from pathlib import Path

root, facade, init_json, fc_json = sys.argv[1:]
sys.path.insert(0, str(Path(root) / 'tools/bisection'))
import teardown

init_doc = json.loads(Path(init_json).read_text())
fc_doc = json.loads(Path(fc_json).read_text())
library = Path(init_doc['library'])
assert Path(fc_doc['library']).resolve().read_bytes() == library.resolve().read_bytes()
layout = teardown.library_layout(library)
text = next(s for s in layout['sections'] if s['name'] == '.text')
prefix = teardown.policy_prefix(library, facade)
assert prefix, 'no policy prefix'


def page(vaddr):
    for s in layout['sections']:
        if s['address'] <= vaddr < s['address'] + s['size']:
            return (vaddr - s['address'] + s['offset']) // 4096
    return ('plt', vaddr // 4096)


# Function bodies in .text, one per start address (aliases share a body).
bodies = {}
for start, size, kind, name in layout['symbols']:
    if text['address'] <= start < text['address'] + text['size'] and kind in 'tTwW':
        if start not in bodies or size > bodies[start][0]:
            bodies[start] = (size, name)
starts = sorted(bodies)


def owner(vaddr):
    import bisect
    index = bisect.bisect_right(starts, vaddr) - 1
    if index >= 0 and vaddr < starts[index] + bodies[starts[index]][0]:
        return starts[index]
    return None


# Instruction lengths for Callgrind addresses.
lengths = {}
dump = subprocess.run(['objdump', '-d', '-w', '-j', '.text', '-j', '.plt', '-j', '.plt.got', str(library)],
                      capture_output=True, text=True, check=True).stdout
for line in dump.splitlines():
    match = re.match(r'^\s*([0-9a-f]+):\t((?:[0-9a-f]{2} )+)', line)
    if match:
        lengths[int(match[1], 16)] = len(match[2].split())

# Init, in first-use order, from Lackey (runtime addresses -> link addresses).
maps = init_doc['maps']
base = min(start for start, _, _, path, _ in maps if path == str(library))
inside = [(start, end) for start, end, _, path, _ in maps if path == str(library)]
init = []
for address, size in init_doc['order']:
    if any(lo <= address < hi for lo, hi in inside):
        init.append((address - base, size))


def callgrind_base(rows):
    """Load bias under Valgrind: the page-aligned value every (address, symbol) agrees on."""
    raw = {}
    for line in subprocess.run(['nm', '-S', '--defined-only', str(library)], capture_output=True, text=True,
                               check=True).stdout.splitlines():
        fields = line.split()
        if len(fields) == 4:
            raw.setdefault(fields[3], (int(fields[0], 16), int(fields[1], 16)))
    low, high = -1 << 62, 1 << 62
    for address, name in rows:
        if name in raw and raw[name][1]:
            start, size = raw[name]
            low, high = max(low, address - start - size + 1), min(high, address - start)
    candidates = [value for value in range(low - low % 4096, high + 1, 4096) if low <= value <= high]
    assert len(candidates) == 1, (low, high, candidates[:4])
    return candidates[0]


def link(rows):
    bias = callgrind_base(rows)
    result = []
    for address, _ in rows:
        vaddr = address - bias
        result.append((vaddr, lengths.get(vaddr, 1)))
    return result


load = link(fc_doc['load']) if fc_doc['load'] else []
first = link(fc_doc['first'])
cg_init = {vaddr for vaddr, _ in link(fc_doc['init'])}
lackey_init = {vaddr for vaddr, _ in init}

# Prefix functions in current order; check that sequential placement with
# alignment min(16, lowbit(start)) reproduces the current addresses.
members = [start for start in starts if prefix[0] <= start < prefix[1]]


def align(start):
    return min(16, start & -start)


def place(order, origin):
    placed, position = {}, origin
    for start in order:
        position = -(-position // align(start)) * align(start)
        placed[start] = position
        position += bodies[start][0]
    return placed, position


current, current_end = place(members, members[0])
mismatch = [hex(s) for s in members if current[s] != s]

used = []
for vaddr, _ in init:
    function = owner(vaddr)
    if function is not None and prefix[0] <= function < prefix[1] and function not in used:
        used.append(function)
outside_init = sorted({owner(v) for v, _ in init if owner(v) is None or not prefix[0] <= owner(v) < prefix[1]},
                      key=lambda value: -1 if value is None else value)
order = used + [start for start in members if start not in set(used)]
after, after_end = place(order, members[0])


def moved(vaddr, placement):
    function = owner(vaddr)
    if function is not None and function in placement:
        return placement[function] + (vaddr - function)
    return vaddr


def pages(instructions, placement):
    result = set()
    for vaddr, size in instructions:
        new = moved(vaddr, placement) if placement else vaddr
        result.update({page(new), page(new + size - 1)})
    return result


def windows(page_set, shift):
    return {((p * 4096 + shift) // 65536) for p in page_set if isinstance(p, int)}


text_pages = (text['offset'] // 4096, (text['offset'] + text['size'] - 1) // 4096)
report = dict(facade=facade, library=str(library), prefix=[hex(prefix[0]), hex(prefix[1])],
              prefix_pages=[page(prefix[0]), page(prefix[1] - 1)], text=dict(address=hex(text['address']), offset=hex(text['offset'])),
              prefix_functions=len(members), model_check=dict(mismatches=len(mismatch), first=mismatch[:5],
                                                              modelled_end=hex(current_end)),
              after_end=hex(after_end),
              init_lackey_vs_callgrind=dict(lackey=len(lackey_init), callgrind=len(cg_init),
                                            only_lackey=len(lackey_init - cg_init), only_callgrind=len(cg_init - lackey_init)),
              init_functions_in_prefix=len(used), init_outside_prefix=[None if v is None else bodies[v][1] for v in outside_init],
              init_bytes=sum(bodies[s][0] for s in used))
first_functions = {owner(v) for v, _ in first}
report['first_candidate'] = dict(instructions=len(first), functions=len(first_functions - {None}),
                                 in_prefix=len({f for f in first_functions if f and prefix[0] <= f < prefix[1]}),
                                 also_in_init=len({f for f in first_functions if f in set(used)}),
                                 outside_prefix=sorted({bodies[f][1] for f in first_functions
                                                        if f and not prefix[0] <= f < prefix[1]})[:10],
                                 bytes_not_in_init=sum(bodies[f][0] for f in first_functions
                                                       if f and prefix[0] <= f < prefix[1] and f not in set(used)))
for label, placement in (('before', None), ('after', after)):
    p_load, p_init, p_first = pages(load, placement), pages(init, placement), pages(first, placement)
    new_first = p_first - p_init - p_load
    report[label] = dict(load_pages=len(p_load), init_pages=len(p_init), first_pages=len(p_first),
                         first_new_pages=len(new_first), m0_m1_pages=len(p_load | p_init | p_first),
                         init_span=[min(p for p in p_init if isinstance(p, int)), max(p for p in p_init if isinstance(p, int))],
                         first_new=sorted(p for p in new_first if isinstance(p, int)),
                         init_text_pages=len({p for p in p_init if isinstance(p, int) and text_pages[0] <= p <= text_pages[1]}))
    win_init = [windows(p_init | p_load, shift) for shift in range(0, 65536, 4096)]
    win_all = [windows(p_init | p_load | p_first, shift) for shift in range(0, 65536, 4096)]
    report[label]['windows_mean'] = dict(m0_i1=sum(map(len, win_init)) / 16,
                                         first_new=sum(len(b - a) for a, b in zip(win_init, win_all)) / 16)
report['first_use'] = [bodies[s][1][:110] for s in used[:15]]
print(json.dumps(report, indent=1))
```
